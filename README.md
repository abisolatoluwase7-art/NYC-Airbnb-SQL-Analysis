NYC Airbnb Data Cleaning & Exploratory Analysis (SQL)

📊 Project Overview
This project focuses on cleaning, querying, and performing exploratory data analysis on the 2019 New York City Airbnb dataset using MySQL Workbench. The goal was to identify missing values, remove duplicates, and extract key business insights regarding property types, pricing trends, and neighborhood availability.



🛠️ Tools & Technologies Used
MySQL Workbench: Database administration, data cleaning scripts, and SQL querying.
Common Table Expressions (CTEs) & Aggregations: Advanced querying for exploratory data analysis and statistical summaries.



📈 Key Insights & Features
Data Cleaning & Auditing: Checked for null values, inspected field constraints, and eliminated duplicate records to ensure data integrity.
Pricing & Neighborhood Trends: Analyzed average listing prices across various NYC boroughs and neighborhoods to spot high-cost versus budget-friendly zones.
Availability & Metrics: Evaluated minimum nights, host listing counts, and room types using advanced aggregate functions and CTEs.
